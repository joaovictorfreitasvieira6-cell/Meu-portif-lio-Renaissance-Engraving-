Este portfólio reúne meu trabalho, meus estudos e uma parte da maneira como percebo o mundo. A engenharia aparece ao lado de gravuras antigas; os circuitos atravessam o cérebro; os servidores dividem espaço com figuras aladas, instrumentos de medida e um tabuleiro de xadrez.

Escolhi essa linguagem porque sou apaixonado por arte e fascinado por tecnologia. Encontro beleza tanto na delicadeza de um traço quanto na estrutura de um sistema. Construir este espaço foi uma forma de aproximar essas duas sensibilidades e dar à minha trajetória uma expressão pessoal.

## A melancolia que habita este espaço

O papel envelhecido, a tinta escura, as expressões das figuras e os movimentos lentos criam uma atmosfera de contemplação. Há algo de distante nessas imagens: a sensação de encontrar um pensamento que permaneceu guardado por muito tempo.

A melancolia que procuro transmitir é a inquietação de quem deseja compreender, criar e continuar aprendendo, mesmo quando o caminho ainda parece incompleto. É o intervalo entre uma pergunta e uma resposta. É olhar para algo que construímos e perceber que ainda existe muito a descobrir.

Em minha leitura de _Melencolia I_, de Albrecht Dürer, os instrumentos, as formas e a figura pensativa sugerem esse encontro entre capacidade e limite. Ter ferramentas não encerra a dúvida. Conhecer uma técnica não elimina a dificuldade de criar. Às vezes, precisamos permanecer diante do problema antes de enxergar o próximo movimento.

Essa interpretação pessoal acompanha minha relação com a engenharia: investigar uma falha, estudar uma arquitetura, refazer uma solução e aceitar que aprender exige tempo.

## Por que escolhi fazer dessa forma

Quis que o visitante pudesse perceber algo de mim antes mesmo de abrir a lista de tecnologias.

As gravuras trazem a atenção aos detalhes que admiro. As marcas do papel sugerem passagem do tempo. As figuras humanas lembram que toda construção técnica nasce de alguém que pensa, experimenta, se engana e tenta novamente.

Nesse cenário, a tecnologia ganha presença por meio de pequenos acontecimentos: um cérebro se reconstrói, a energia percorre seus circuitos, engrenagens giram e um terminal escreve suas primeiras linhas. Cada movimento participa da composição e aproxima a imagem antiga de um sistema vivo.

A navegação em capítulos acompanha essa intenção. O visitante atravessa as cenas como quem percorre um acervo, com espaço para olhar e abrir os textos que despertarem curiosidade.

## O violino e a tristeza que a imagem passa a carregar

A trilha escolhida, **Absent Haven**, acrescenta uma dimensão emocional ao percurso.

Para mim, o som do violino tem uma proximidade particular com a voz humana. Uma nota sustentada pode lembrar uma hesitação; o vibrato pode sugerir fragilidade; a pausa entre duas frases pode fazer sentir uma ausência. Ao acompanhar uma imagem, esses gestos sonoros mudam a maneira como permanecemos diante dela.

Uma figura imóvel passa a parecer envolvida em uma lembrança. Um olhar ganha distância. O papel envelhecido parece guardar uma história que não foi inteiramente contada. A tristeza chega como uma possibilidade de leitura, e cada pessoa pode senti-la de uma forma diferente.

Escolhi essa combinação porque ela expressa a sensibilidade que queria dar ao portfólio: beleza, inquietação e vontade de continuar. Enquanto a música sustenta essa atmosfera, os circuitos continuam acesos e as engrenagens seguem em movimento.

A reprodução possui controle de pausa e volume. Quando o navegador impede o início automático, a trilha começa após uma interação do visitante.

As cenas incluem releituras e composições digitais inspiradas em obras antigas. Os significados apresentados nos textos expressam minha interpretação pessoal.

## A engenharia por trás da experiência

O site funciona com **HTML, CSS e JavaScript nativos**, sem framework de interface e sem etapa de compilação. Os efeitos são executados no navegador; as dependências de desenvolvimento apoiam a formatação e os testes.

| Tecnologia                      | Uso no projeto                                                                          |
| ------------------------------- | --------------------------------------------------------------------------------------- |
| **HTML semântico**              | Estrutura das seis telas, navegação, janelas de leitura e descrições acessíveis.        |
| **CSS**                         | Composição, tipografia, cores, espaçamentos, tela cheia e animações visuais.            |
| **JavaScript com ES Modules**   | Organização dos controladores, interfaces, configurações e efeitos.                     |
| **Canvas 2D**                   | Reconstrução do cérebro por partículas e rastro de tinta do cursor.                     |
| **SVG**                         | Caminhos dos pulsos de energia, mecanismos, ícones e elementos sobrepostos às gravuras. |
| **Web Animations API**          | Transição de pergaminho entre os capítulos.                                             |
| **HTMLMediaElement / Audio**    | Reprodução da trilha, volume, pausa e repetição a partir de 18 segundos.                |
| **Node.js**                     | Servidor local, verificação de referências e execução dos testes.                       |
| **Node Test Runner + LinkeDOM** | Testes de comportamento e integração em um DOM simulado.                                |
| **Prettier**                    | Formatação consistente de HTML, CSS, JavaScript e documentação.                         |

A tipografia dos textos editáveis utiliza **Cormorant Garamond** e **EB Garamond**. Textos incorporados às imagens fazem parte da própria arte.

### Organização do código

```text
index.html              Estrutura e composição das telas
assets/                 Gravuras, imagens, ícones e trilha sonora
src/
  main.js               Inicialização da aplicação
  config/               Capítulos, links e configuração de áudio
  content/              Textos e mensagens dos terminais
  core/                 Navegação, áudio e ciclo de vida
  ui/                   Controles, janelas e transição visual
  features/             Partículas, terminais e demais efeitos
  styles/               Base, componentes, capítulos e animações
scripts/                Servidor local e verificações
tests/                  Testes automatizados
```

A arquitetura aplica princípios de **SOLID por composição**: cada módulo possui uma responsabilidade, os controladores recebem suas dependências e as interfaces expõem operações pequenas. O conteúdo fica separado do comportamento. Eventos, temporizadores e animações possuem limpeza de recursos.

O projeto também inclui navegação por teclado nas abas, identificação dos controles para leitores de tela, opção de pular a abertura e respeito à preferência de movimento reduzido.

## Executar localmente

Com Node.js e npm instalados:

```sh
npm install
npm run dev
```

Acesse **http://127.0.0.1:5173**. O Live Server do VS Code também pode servir o projeto. Utilize um servidor HTTP para carregar os módulos JavaScript.

### Verificações

```sh
npm test
npm run check
npm run format:check
```

Para aplicar a formatação:

```sh
npm run format
```

Os testes cobrem navegação, transições, abas, janelas de leitura e comportamento do áudio. A conferência visual das gravuras e sobreposições deve ser feita no navegador.
